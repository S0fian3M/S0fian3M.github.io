# Personal website

Heavily inspired by https://mimuki.net/ design and code.

To compile the HTML from the md, run './scripts/build_all.sh'.

To run locally, don't forget to set up the local server, such as with: python3 -m http.server.

You need to create a index.md in each folder if you want to automatically fill it with the list of every elements within the folder and act as a navigation page.
