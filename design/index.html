design principles of this website

  • focus on what matters: having an academic personal website, having a place to dump some thoughts I have never seen elsewhere
  • one page for one idea, one page for one project, one page for one thing (cf Zettelkasten method)
  • autonomy and manageability

That's why:

  • I write everything here in markdown
  • no Javascript or additional features to maintain
  • no 'fancy' design
